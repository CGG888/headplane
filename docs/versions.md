# 版本记录

**HeadplaneCN**（[`CGG888/headplaneCN`](https://github.com/CGG888/headplaneCN)）的版本记录：
下面表格中的每一行都对应本分支的一个发行版本，说明该版本相对上游原版 Headplane 做了什么。
每行只是一句概括，权威的变更说明与升级须知以[更新日志](/CHANGELOG)为准；版本号与容器镜像标签
（`ghcr.io/cgg888/headplanecn:<版本>`）一一对应。

表格沿用 README 中的原始列布局（单列「版本 / 内容」），未做拆分；内容较长，窄屏下可左右滚动查看。
