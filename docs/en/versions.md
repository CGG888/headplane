# Version history

Every row below is one release of this fork ([`CGG888/headplaneCN`](https://github.com/CGG888/headplaneCN))
and what it changed relative to upstream Headplane. The release notes themselves are written and
maintained in **Chinese** by the maintainer, so the table is reproduced here **as-is** rather than
translated — a machine translation would drift from the authoritative wording. Version numbers match
the container image tags (`ghcr.io/cgg888/headplanecn:<version>`).

For the authoritative prose changelog and upgrade notes, read the [Changelog](/en/CHANGELOG).
The Chinese version of this page is [版本记录](/versions).

The table keeps its original layout from the README (a single version / content column pair) and is
scrollable horizontally on narrow screens.
